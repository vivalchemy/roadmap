## Features:

- Generate roadmap topics from topic
```sh
roadmap generate "topic"
roadmap -g "topic"
```

- Generate roadmap files from yaml files
```sh
roadmap example.{yaml,yml}
roadmap -f "example.yaml"
```

- Regenerate the subtopic files from the previous markdown files
```sh
roadmap example.md
roadmap -f "example.md"
```
